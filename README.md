# Long Hải Securitas — Web Doanh nghiệp, Tuyển dụng & Cổng Nhân viên

Nền tảng Full-stack hợp nhất cho **Công ty Cổ phần Dịch vụ Bảo vệ Long Hải (Securitas Vietnam)**:

- **Website Doanh nghiệp & Tuyển dụng (Công khai):** `/`, `/gioi-thieu`, `/dich-vu`, `/tuyen-dung` (kèm công cụ tính thử thu nhập & ứng tuyển nhanh 30 giây), `/lien-he` (kèm form khảo sát báo giá B2B).
- **Cổng Nhân viên (`/nhan-vien`):** Theo dõi lịch trực, ước tính thu nhập và quản lý chi tiêu.
- **Cổng Quản trị HR (`/admin`):** Quản lý tin tuyển dụng, hồ sơ ứng viên và yêu cầu báo giá.

## Deploy nhanh 1-click lên Render (Miễn phí)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/lehongson2005/longhai)

> File cấu hình [`render.yaml`](./render.yaml) và [`Dockerfile`](./Dockerfile) đã được thiết lập sẵn (Server Singapore, tự build Frontend + Backend, tự tạo `JWT_SECRET`, healthcheck `/api/health`).
